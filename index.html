自己紹介

佐藤 勝 / 品質保証と業務システム開発

製造業の品質保証部門で、分析業務と並行して業務システムの内製開発を行っています。 現場の測定・校正・記録の流れを理解したうえで、社内データベースを中心に パソコン向けアプリと Web 画面を設計・実装しています。

AI を使った実装・レビューも活用しつつ、共通化、設定の外出し、自動テスト、 インストーラー配布など、運用後も保守しやすい設計を続けています。 社内の技術発表会での発表経験もあります。

  • 担当範囲: 要件整理 / 設計 / 実装 / テスト / 導入 / 保守
  • 主な領域: 測定機器の台帳管理、分析データの保存、測定器からの自動取込
  • 志向: 現場課題を理解し、設計から運用まで価値を出せる DX 人材

強み

技術名の列挙より先に、仕事で重視している点です。

現場の仕事から設計する

校正期限、作業前点検、承認、外部校正など、品質保証の実務の流れを踏まえて画面とデータを設計します。現場に残る運用を前提にします。

配って使える完成度

社内ツールでも、自動テスト、権限設計、専用アカウント、パスワード保護、インストーラーと自動更新まで含めます。「動く試作」ではなく「渡して使える状態」をゴールにします。

横展開できる共通部品

データベース接続、設定、ログ、インストーラー、自動更新、キーボード入力などを共通部品化し、新しいアプリを速く安定して立ち上げます。

社内発表資料

品質保証の測定記録デジタル化について、社内発表会で説明した資料です。どのような改善を行ったかを知ってもらうために掲載しています。

制作物 02 測定器連携 / 複数PC配信

共有測定器のデータを複数PCへ届ける中継システム

1台の測定器しかない出力を、中継パソコン経由で複数の測定用パソコンへ安全に振り分けられるようにしました。

課題
共有の測定器は出力が1系統しかなく、複数のパソコンで同時に使うことや、関係ない端末への流入防止が難しい
対応
中継パソコンで受信して社内ネットワークへ配信。受け取る側は認証後に仮想の通信ポートへ出し、既存の測定ソフトへつなぐ
工夫
データの読み取り、振り分け、常駐運用を分けて設計。自動テストとインストーラー配布で現場展開できる形にした

設計で意識していること

01

業務ルールを一つに保つ

管理台帳では、パソコン版と Web 版が同じ業務処理を参照します。画面は違っても、判定や権限の考え方は揃えます。

02

現場へ渡せるところまで完成とみなす

実行ファイル化、インストーラー、自動更新、二重起動防止、ログ、設定の外出しまで、最初から設計に含めます。

03

権限と秘密情報も設計対象にする

アプリ専用のログイン、必要最小限の権限、パスワードの暗号化保存など、配ったあとのリスクも扱います。

04

実際の測定器とつながる前提で作る

無線、ケーブル通信、社内ネットワーク配信、装置通信など、実機前提で設計し、検証用の模擬環境も用意します。
