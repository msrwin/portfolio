自己紹介

面接の冒頭でお伝えする内容です。

製造業の品質保証部門で、分析業務と並行して業務システムの内製開発を行っています。 現場の測定・校正・記録業務を理解したうえで、SQL Server を中心に PyQt デスクトップアプリと React / FastAPI の Web を設計・実装しています。

Cursor を中心に複数 AI を組み合わせた実装・レビューも活用しつつ、 共通化・設定外部化・pytest・MSI 配布など、運用後の保守性を意識した設計を続けています。 社内技術発表会での発表経験もあります。

  • 担当範囲: 要件整理 / 設計 / 実装 / テスト / 導入 / 保守
  • 主な領域: 測定機器台帳、分析データ管理、計測器からの自動取込
  • 志向: 現場課題を理解し、設計から運用まで価値を出せる DX エンジニア

代表作 02 分散 / MQTT / シリアル

設計で意識していること

01

業務ロジックの単一化

管理台帳では Desktop と Web が同じ services 層を参照します。画面差は吸収しつつ、判定や権限の二重実装を避けます。

02

現場導入まで含めた完成定義

EXE / MSI、自動更新、単一起動、ログ、設定外部化までを最初から設計に含めます。

03

権限と秘密情報の扱い

アプリ専用ログイン、最小権限、DPAPI による秘密保護など、配布後の運用リスクも設計対象にします。

04

実機プロトコルとの接続

BLE・シリアル・MQTT・TCP など、実機前提で設計し、検証用の仮想環境も用意します。
